# Фикслаб — сайт сервиса ремонта телефонов + Google Таблица

Одностраничный сайт: услуги и цены, форма заявки. **Цены сайт берёт из Google Таблицы, заявки пишет туда же** — владелец меняет прайс в таблице, разработчик не нужен.

Чистые HTML/CSS/JS без сборки и зависимостей — подходит любой статический хостинг (Cloudflare Pages, GitHub Pages, обычный хостинг).

> «Фикслаб», адрес и телефон — условные, это демо-версия.

## Быстрый старт

```bash
node scripts/serve.mjs          # http://localhost:4173/
```

Откройте страницу и нажмите **«Таблица цен (демо)»** в правом нижнем углу: поменяйте цену в листе «Цены» — прайс на сайте обновится; отправьте заявку — она появится строкой в листе «Заявки».

## Подключение своей таблицы за 10 минут

### 1. Таблица (2 мин)
Создайте Google Таблицу с двумя листами. Первая строка — заголовки, как здесь:

**Лист «Цены»**

| brand | model | service | price | duration | note |
|---|---|---|---|---|---|
| Apple | iPhone 13 | Замена экрана | 9990 | 30 мин | OLED |
| Samsung | Galaxy S23 | Замена аккумулятора | 4990 | 40 мин | |
| Google | Pixel 7 | Замена задней камеры | | 1–2 дня | под заказ |

- `price` — число в рублях (можно «9 990»); пустая ячейка → на сайте «по запросу».
- `brand` вне Apple/Samsung/Xiaomi попадает во вкладку «Другие».
- Порядок строк = порядок карточек на сайте. Готовый пример — `data/prices.csv` (Файл → Импорт).

**Лист «Заявки»** — можно оставить пустым: скрипт сам создаст заголовки
`created_at, name, phone, model, issue, comment, source, status`.

### 2. Публикация цен (1 мин)
Файл → Поделиться → **Опубликовать в интернете** → лист «Цены» → формат **CSV** → Опубликовать. Скопируйте ссылку (`https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&single=true&output=csv`).

> Google обновляет опубликованный CSV с задержкой до ~5 минут. Сайт держит последнюю удачную версию прайса в браузере и покажет её, если таблица недоступна.

### 3. Приём заявок (4 мин)
1. В таблице: Расширения → **Apps Script**, удалите шаблонный код и вставьте `apps-script/Code.gs`. Сохраните.
2. **Развернуть → Новое развертывание** → тип «Веб-приложение»: выполнять от имени «Я», доступ «Все». Разрешите доступ к таблице.
3. Скопируйте URL веб-приложения (`https://script.google.com/macros/s/…/exec`). Проверка: открытый в браузере URL отвечает `{"ok":true,…}`.

Скрипт пишет заявку строкой в лист «Заявки» (с блокировкой от одновременной записи), отбрасывает ботов (скрытое поле-ловушка) и экранирует значения, похожие на формулы.

**Уведомления в Telegram (необязательно).** Создайте бота у @BotFather, узнайте свой chat_id (например, у @userinfobot). В Apps Script: ⚙ Настройки проекта → Свойства скрипта → добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Токен в коде не хранится.

> После правок `Code.gs` нужно «Развернуть → Управление развертываниями → Изменить → Новая версия», иначе работает старая версия.

### 4. Настройка сайта (1 мин)
В `config.js`:

```js
window.FIXLAB_CONFIG = {
  PRICES_CSV_URL: 'https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&output=csv',
  LEADS_ENDPOINT: 'https://script.google.com/macros/s/…/exec',
  DEMO_MODE: false, // убрать демо-панель
};
```

### 5. Публикация (2 мин)
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → перетащите папку проекта (без `tests/`, `scripts/`, `docs/` — они не нужны, но и не мешают). Либо подключите Git-репозиторий: build command пустой, output directory `/`.
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- Обычный хостинг: загрузите файлы по FTP.

Не забудьте заменить `https://fixlab.example/` в `index.html` (canonical, Open Graph, JSON-LD) и реквизиты в футере.

## Как это устроено

```
index.html               разметка всех секций, SEO, JSON-LD LocalBusiness
config.js                URL таблицы и Apps Script, DEMO_MODE
assets/css/styles.css    дизайн-система (токены, компоненты) и адаптив
assets/js/app.js         загрузка прайса, табы, поиск, форма, связка с демо-панелью
assets/js/prices.js      разбор CSV, нормализация, фильтр, форматирование (чистые функции)
assets/js/leads.js       маска телефона, валидация, отправка заявки
assets/js/demo-sheet.js  демо-панель «Google Таблица»
data/prices.csv          демо-прайс (40 строк)
apps-script/Code.gs      приём заявок в таблицу (+ Telegram)
tests/                   юнит-тесты (node --test)
scripts/serve.mjs        локальный сервер
scripts/screenshot.mjs   скриншоты через Edge/Chrome headless (DevTools Protocol)
```

- Цены: `fetch(PRICES_CSV_URL || 'data/prices.csv')` → разбор CSV → карточки моделей. Кэш в `localStorage`; при ошибке сети показываются сохранённые цены с предупреждением.
- Заявки: валидация в браузере → `POST` (`mode: 'no-cors'`, `URLSearchParams`) в Apps Script. Защита от спама: скрытое поле + форма не уходит быстрее чем через 3 секунды.
- Демо-режим: правки цен и заявки хранятся только в браузере посетителя, кнопка «Сбросить демо» в панели всё очищает.

## Разработка

```bash
node --test "tests/**/*.test.mjs"     # или npm test — юнит-тесты, без зависимостей
node scripts/screenshot.mjs desktop:1440xfull mobile:390xfull   # в docs/screenshots/
```

Состояния для скриншотов включаются параметрами адреса: `?demo=open`, `?demo=open&sheet=leads`, `?form=success`, `?form=errors`, `?prices=error`, `?q=экран`, `?brand=Apple`.
