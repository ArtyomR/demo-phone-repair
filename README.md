# Фикслаб — демо-сайт сервиса ремонта телефонов

Одностраничный сайт сервиса ремонта: услуги и цены по брендам и моделям, поиск по прайсу, форма заявки. В демо-версии рядом с сайтом открывается панель «Google Таблица» — она показывает, как владелец мог бы управлять прайсом и видеть заявки без участия разработчика.

**Посмотреть сайт:** https://artyomr.github.io/demo-phone-repair/

Чистые HTML/CSS/JS без сборки и зависимостей.

> «Фикслаб», адрес и телефон — условные, это демо-версия. Подключение реальной таблицы и приём настоящих заявок в ней не предусмотрены.

## Что можно посмотреть

- **Прайс** — карточки моделей с услугами, ценами и сроками; вкладки по брендам (Apple, Samsung, Xiaomi, «Другие») и поиск.
- **Форма заявки** — маска телефона, проверка полей, сообщения об ошибках и об успешной отправке.
- **Демо-панель «Таблица цен (демо)»** (кнопка в правом нижнем углу):
  - на листе «Цены» можно поменять цену — прайс на сайте сразу обновится;
  - отправленная через форму заявка появляется строкой на листе «Заявки».

Все изменения хранятся только в браузере посетителя и никуда не отправляются. Кнопка «Сбросить демо» в панели возвращает исходное состояние.

## Как запустить

Сайту нужен любой локальный статический сервер (при открытии `index.html` напрямую из файла браузер не загрузит прайс). Например:

```bash
python -m http.server 4173      # затем откройте http://localhost:4173/
```

## Как это устроено

```
index.html               разметка всех секций, SEO, JSON-LD LocalBusiness
assets/css/styles.css    дизайн-система (токены, компоненты) и адаптив
assets/js/app.js         загрузка прайса, табы, поиск, форма, связка с демо-панелью
assets/js/prices.js      разбор CSV, нормализация, фильтр, форматирование (чистые функции)
assets/js/leads.js       маска телефона, валидация формы заявки
assets/js/demo-sheet.js  демо-панель «Google Таблица»
data/prices.csv          демо-прайс (40 строк)
```

- **Цены:** демо-прайс загружается из `data/prices.csv` → разбор CSV → карточки моделей. Последняя удачная версия кэшируется в `localStorage`; если загрузка не удалась, показываются сохранённые цены с предупреждением.
- **Заявки:** валидация в браузере; в демо-режиме заявка сохраняется локально и отображается в демо-панели. Защита от спама: скрытое поле-ловушка и запрет отправки быстрее чем через 3 секунды.
- **Демо-режим:** правки цен и заявки живут только в браузере посетителя.
